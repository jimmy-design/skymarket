## Mpesa Payment Plugin for Botble CMS

This plugin helps you integrate Mpesa payment gateway into the eastmatt eCommerce system.

### Installation

- Download and unzip the module.
- Copy and paste it into the `platform/plugins/mpesa` folder.
- Go to **Admin Panel** -> **Plugins** and activate the Mpesa payment plugin.
- Go to **Admin Panel** -> **Settings** -> **Payment Gateways** and configure Mpesa payment settings.
